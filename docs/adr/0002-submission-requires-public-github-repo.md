# Submitting hours requires a public, linked GitHub repo

Tracking is unconditional: private repos, unlinked folders and non-Git Projects are all fully tracked, and their stats are visible to the owner. Submitting hours to a Hack Club program, however, requires the Project to be linked to a **public (open-source) GitHub repo**. Reviewers and Fraud Squad need commit history to align against anchored time. We considered letting private or unlinked Projects through with Yellow-only review, and rejected it because those Projects have nothing an external party can check.
